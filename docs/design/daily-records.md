# 时迹 · UI / UX

更新：2026-10-22。本方案为当前实现规范，替代此前地图首页、全天24小时边界和逐字段录入方案。

## 记录优先

四个一级 HdsTabs：记录、地点、统计、我的。沿用 Dashboard 的 HdsNavigation、250vp悬浮栏、28vp底距、92vp遮罩和材质；二级页共用 NavPathStack。

列表像简洁的 Markdown 日记：日期导航 → 睡觉 → 时间＋事项纯文本行 → 起床。根据用户明确要求，从晚到早排序；日期自然分成独立页面。取消总时长摘要、逐条卡片、分类徽章和说明文案。起床/睡觉未记录时显示未设置，不猜测用户作息；轻点任一边界进入作息页。左右滑动、前后按钮、系统日历及回到今天均保留。

以醒来的日期组织跨夜记录。23:30–03:00仍属于起床当天，明确标注次日；已记录次日睡觉时间时，过零点继续当前页，直到睡觉时间后开启新一天；手动查看历史时保持所选日期。无作息数据时按日历日期切换。周视图保留周一到周日网格、固定小时轴、日头跳回列表和记录点击编辑；延伸至实际次日时间，短时段/时间点用可点击色条，避免文字溢出。

## 输入与修改

新增页默认仅显示日期、多行输入框与更多。可直接输入或粘贴：

```text
7:25起床
8:00-9:30 高数
12:10 吃饭
23:30-3:00 开发
3:00睡觉
```

无需额外点提取。保存时本地识别、推断分类并提交；支持项目符号、中文冒号和中文时间。起床/睡觉写入当天作息，其他记录保留事项原文和复合事项。单个时间点无需虚构结束时间；重叠记录允许保存。每次最多100行，一行无效则整批不提交，错误时保留输入。规则识别不联网。

更多内提供单条起止时间的系统选择器、分类、可选已有地点和备注。编辑保持一条记录，保留UUID与创建时间。保存/删除均放在二级页原生 titleBar menu；作息的保存/重置、记忆保存和到访保存同样位于标题栏。正文和底部不再放保存按钮。离开未保存修改与删除保留确认。

## 统计与地点

统计分每日/本周，共享所选日期；显示累计时长、分类饼图及列表、单项周柱状图。重叠事项分别累加，标签使用累计，含义为各项记录时长之和；时间点计0分钟，不伪造时长。空状态不展示示例数据，周柱保留零值日期。

地点独立为重要一级标签，保留地图/地点分段、筛选、定位、到访和记忆。时间记录可关联已有地点，不把旧到访转换成虚构时间事项。在线地图仍需要AGC配置。

## 我的与品牌

直接对照 Dashboard MyPage：100vp分层图标、30vp/800强调色品牌、20vp/600副标题 → 分隔线 → 内嵌设置（用户名、振动、材质、缓存）→ 账号与同步 → 帮助（更新日志、关于）→ 版本与版权。54vp HdsListItemCard、20vp资源箭头、14vp组间距、5组首次激活动画与840vp以上4:6分栏保持一致。

应用名时迹，副标题时间与地点。图标暂定采用日历记录页与独立地点标记，以纸张、冰蓝玻璃及珊瑚色形成轻立体层次，app_icon内保存1024×1024透明前景和不透明背景；无预制边框，通过layered_image及DrawableDescriptor渲染。包名和数据库名保持稳定，保留已安装用户数据。

## 统一视觉与数据

复用Dashboard工具、语义色、安全区、pageTransition、分组入场及按压光效。纯文本行保留0.985缩放/130ms弹簧、pressVisualEffect和pressLightFieldFilter；设置尊重原有偏好。页面显式顶部对齐、100vp标题避让和110vp底部留白。UI不写SQL，domain不导入平台Kit。

Schema v4通过事务迁移保留原Place、Visit与Activity身份、时间、备注；新增day_routines，允许跨夜和时间点，取消时间重叠限制，保留地点引用保护。多行与作息在同一事务保存。两项作息清空仅删除作息，不删除当天记录。
